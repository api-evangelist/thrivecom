# RingCaptcha (ThriveCom)

> RingCaptcha is a phone-verification and two-factor authentication (2FA) platform. It sends one-time passcodes over SMS, voice, WhatsApp and missed-call (Blink), normalizes and validates phone numbers, and scores fraud signals to block fake signups and spam leads. The REST API is served from api.ringcaptcha.com and authenticated with per-application api_key / secret_key / app_key credentials.

## API
- [RingCaptcha Verification API docs](https://my.ringcaptcha.com/docs/web): OTP send/verify, phone normalization, and fraud metadata over a form-encoded REST API at https://api.ringcaptcha.com/{app_key}/{endpoint}.
- [Developer docs (Notion)](https://ringcaptcha.notion.site/Dev-Docs-e2af75c9765349848ad53c8601a8217f)

## Operations
- POST /{app_key}/captcha — issue a verification session token
- POST /{app_key}/normalize — normalize a phone number to E.164
- POST /{app_key}/code/sms — send an OTP over SMS
- POST /{app_key}/code/voice — send an OTP over voice call
- POST /{app_key}/verify — verify a user-entered pincode against a token
